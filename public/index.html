Production Readiness & System Design Decisions

Implementation notes for interview evaluation

1. NULL Bonus Handling

SQL operations with NULL naturally yield NULL. All aggregation queries use COALESCE(SUM(Bonus), 0) to guarantee mathematical correctness. In rankings, ORDER BY CASE WHEN Bonus IS NULL THEN 1 ELSE 0 END ASC, Bonus DESC guarantees NULL values are placed last deterministically.

2. Secrets & Configuration

Zero database credentials or paths are hardcoded. Database configuration is dynamically loaded from process.env.DATABASE_PATH or Azure App Settings.

3. 5% Default Bonus: Read-Time Rationale

We chose read-time projection over write-time table mutation. Writing to the DB destroys auditability by permanently erasing whether a bonus was genuine or a default fallback. Read-time calculation also accommodates policy updates with zero DB migrations.
